# Distance Calculator

# Description
 Calculates the distance between two points

# How to run the program
 Input the missing variables and let the program calculate the distance between two points

 # Input Needed
  - x1
  - y1
  - x2
  - y2

# Sample Output
Enter x1: 2
Enter y1: 4
Enter x2: 5
Enter y2: 8
Distance is equal to: 5.0
